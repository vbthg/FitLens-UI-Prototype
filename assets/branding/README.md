# Temporary notification preview icon

fitlens-notification-preview.svg is a TEMPORARY onboarding illustration asset, not an approved final app icon.

The current project has no selected production app icon / icon manifest. Existing private-review/branding symbols are studies and are explicitly described there as unapproved. This preview therefore reuses the existing FitLens happy face from mascot-face.js on the existing forest-green palette. The face is static within the icon; no animated mascot is embedded in the notification body.

Replace this asset with the approved app-icon artwork before native integration. The native notification uses the app icon installed in the iOS application bundle, not this HTML img tag or a per-notification arbitrary image.
